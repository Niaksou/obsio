Recommandation : la piste D

Le mélange tient ses promesses. Le O multibrin se lit comme un câble, et il est dans le nom : on ne peut pas séparer Obsio de son symbole. Le prix à payer est une version simplifiée pour les très petits formats (favicon), aux mêmes couleurs, ce que font la plupart des marques.

La piste E, gaine encre, est à écarter : sans contraste, le câble disparaît. La piste C reste la solution la plus simple si l’on veut une marque imprimable en deux couleurs seulement.
